A modern, offline-capable Progressive Web App for language learning powered by the FSRS (Free Spaced Repetition Scheduler) algorithm. Master vocabulary across multiple languages with scientifically-proven spaced repetition and 7 diverse exercise types.

**🎯 Key Highlights:**
- 🧠 **FSRS Spaced Repetition** - Scientifically optimized review scheduling
- 📱 **Offline-First PWA** - Learn anywhere, anytime with IndexedDB caching
- 🎮 **7 Exercise Types** - Flashcards, typing, multiple choice, listening & speaking
- 📊 **Smart Scoring System** - 0-100 vocabulary mastery score based on FSRS metrics
- 🌐 **Multi-Language Support** - English ↔ Russian, English ↔ Serbian
- 📖 **Integrated Dictionary** - MyMemory API with intelligent caching
- 📥 **Import/Export** - CSV and JSON support for vocabulary management
